============================================================
  Experiment A — 70/30 IO/CPU  |  FIFO
============================================================
  Policy            : FIFO
  IO ratio          : 70% IO / 30% CPU
  Tasks completed   : 1000 (299 CPU + 701 IO)
  Makespan          : 39188.0 ms  (39.2 s)
  Avg wait time     : 8979.1 ms
  Max wait time     : 18461.3 ms
  Avg turnaround    : 9179.7 ms
  Avg CPU usage     : 89.5%
  Avg active workers: 5.12 / 8
  Peak queue length : 465

  Interpretation:
  FIFO suffers from head-of-line blocking. When 2 CPU tasks are running
  (70% CPU used), a third CPU task at the queue head blocks all IO tasks
  behind it even though 30% CPU budget remains. Result: avg wait of 8979ms,
  max wait of 18461ms, and only 5.12/8 workers active on average.
